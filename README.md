# ADR Identification Basics: Task 1

## Case Summary

| Item | Details |
|---|---|
| Patient | Female, 45 years |
| Presenting symptoms | Rash, itching, nausea, dizziness |
| Suspected drug | Amoxicillin (started 5 days ago) |
| Concomitant drug | Paracetamol, as required |
| Typical reaction | Itching (urticaria) with rash |

### Timeline

| Day | Event |
|---|---|
| Day -5 | Amoxicillin started |
| Day -2 | Symptoms started |
| Day 0 | Symptoms ongoing |

## Assessment

Symptoms began about 3 days after amoxicillin was started, which fits a delayed-type penicillin hypersensitivity reaction. Rash and pruritus are well-documented amoxicillin ADRs, and nausea is a common GI side effect.

Paracetamol is very unlikely to be responsible. It is only taken when needed, and rash from paracetamol is uncommon.

Dizziness should prompt consideration of early systemic allergy.

| # | Question | Answer | Score |

| 3 | Improved on stopping the drug? | Unknown | 0 |

| 9 | Similar reaction to the same or similar drug before? | Not known | 0 |
| 10 | Objective evidence? | Not available | 0 |
| | **Total** | | **3 = Possible** |

Scale: 9 or more (definite), 5-8 (probable), 1-4 (possible), 0 or less (doubtful).

## WHO-UMC Causality

**Possible.** This becomes Probable/Likely if there is a positive dechallenge and no other cause.

## Differential Diagnoses

- Viral exanthem
- The infection being treated
- Other new medications, foods or supplements

## Management Plan

1. Assess severity (airway, angioedema, blisters, mucosal involvement, fever) and take vital signs.
2. Discontinue amoxicillin and use an alternative antibiotic that is not a beta-lactam.
3. Give symptomatic treatment (antihistamine) and watch for improvement.
4. Record on the patient's chart that the patient may be allergic to penicillin.
5. Report to the Ghana FDA using the ADR reporting form.
